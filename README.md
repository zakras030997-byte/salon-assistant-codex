# Salon Assistant for Codex

Открытый пакет скиллов для персонального помощника мастера салона: клиентская база по скриншотам переписок, сеансы в Google Calendar, учёт материалов по фотографиям и сохранение результатов командой «Обнови базу». Лицензия [MIT](LICENSE). Версия **0.7.0**, прототип.

Изображения читает Codex. Запись выполняется через отдельно подключённые Google Drive/Sheets и Google Calendar. Собственный сервер, отдельный OCR-сервис и ключ OpenAI API для этого пакета не требуются. Для работы нужен доступ к Codex и соответствующим Google-плагинам; лицензия пакета не включает сторонние подписки.

## Установка

Передайте Codex ссылку на этот репозиторий и попросите установить пакет в отдельный локальный проект. Репозиторий публичный: пароль GitHub не нужен. Агент читает [INSTALL.md](INSTALL.md), проверяет Python 3.10+ и выполняет локальную установку.

Затем откройте созданный рабочий проект в Codex, начните новую задачу и напишите «Привет». Мастер помогает подключить собственный Google-аккаунт, создать или привязать папки и таблицы, задаёт вопросы по одному и запрашивает образец клиентской базы файлом или скриншотом. Перед рабочими изменениями показывает конкретную сводку для подтверждения и проверяет сохранённый результат.

## Что входит

| Навык | Назначение |
|---|---|
| `svetlana-assistant` | Начало сессии и выбор сценария |
| `svetlana-first-run` | Google-подключение, структура проекта и персонализация |
| `svetlana-client-photo` | Клиентская база и карточки по фото/скриншотам |
| `svetlana-calendar-booking` | Запись, перенос и отмена сеанса с проверкой базы и календаря |
| `svetlana-stock-photo` | Приход, расход и сверка остатков по фотографиям |
| `svetlana-update-base` | «Обнови базу»: лиды, клиентская база, карточки и итоги задач |

Идентификаторы `svetlana-*` сохранены от первого прототипа. Имя пользователя, обращение, услуги, график и материалы задаются в мастере. Значения по умолчанию — Санкт-Петербург и `Europe/Moscow`; их можно изменить явным запросом.

## Структура проекта

На Google Drive: `system`, `Клиенты`, `Склад` и таблица «Оперативная память». В «Клиенты» сразу создаются нативные «Клиентская база» и «Лиды»; предоставленные позже клиентские данные переносятся в тот же файл базы. В «Склад» находится «База данных склада». Настройки и журнал операций хранятся в `system`.

После настройки напишите **«Обнови базу»** в рабочем проекте. Обращения до договорённости попадут в лиды; подтверждённые клиентские сведения — в базу и карточку; результаты конкретной работы — в оперативку со ссылками. Уже подтверждённые факты сохраняются без повторного согласия. Неясные сведения уточняются; повторная команда без изменений не создаёт дублей. Сама команда не отправляет сообщения, не создаёт сеансы и не списывает материалы.

Локальный установщик размещает ядро в `system/assistant`, создаёт маршруты `.agents/skills` и корневой `AGENTS.md`. Он подключает навыки к этому проекту, не регистрирует глобальный плагин в каталоге Codex. В пакете сохранён `.codex-plugin/plugin.json` для отдельной упаковки в marketplace.

## Готовность и ограничения

Проверены установщик, первый запуск и сквозной сценарий на вымышленных данных: Google Drive/Sheets, запись и отмена сеанса, проверка повтора и склад. [Отчёт проверки](VALIDATION.md). Установка на устройстве пользователя, его Google-вход и качество чтения реальных фотографий проверяются отдельно при передаче.

Фото этикетки не доказывает фактический остаток. Нечитаемые данные не угадываются. Повторный скриншот или потерянный ответ не должны приводить к повторному списанию или второму сеансу. Проверка календаря не блокирует одновременные ручные изменения; при неоднозначном результате требуется сверка. Автосписание по услуге, рассылки клиентам и фоновая синхронизация не входят в эту версию.

В публичных исходниках нет рабочих таблиц, фотографий, заполненного профиля, OAuth-токенов или Google-ID разработчика. Рабочая папка пользователя хранится отдельно от репозитория. Для обновления 0.6.2 → 0.7.0 агент использует `--upgrade` по [инструкции](INSTALL.md): установщик сохраняет Google-привязку и пользовательские файлы, останавливается при ручной правке исходников. При первом «Обнови базу» мастер добавляет недостающую привязку лидов и схем без повторной анкеты.

## Разработка

Python 3.10+, стандартная библиотека:

```bash
python3 -B -m unittest discover -s tests -v
```

При изменении скиллов проверяйте реальные сценарии и ссылки. При отправке примеров и сообщений об ошибках используйте вымышленные данные. Пакет распространяется на условиях [MIT](LICENSE).
