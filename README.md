# Salon Assistant for Codex

Открытый плагин Codex для персонального помощника мастера салона: клиентская база по скриншотам переписок, сеансы в Google Calendar, учёт материалов по фотографиям и сохранение результатов командой «Обнови базу». Лицензия [MIT](LICENSE). Версия **0.8.2**, прототип.

Изображения читает Codex. Запись выполняется через отдельно подключённые Google Drive/Sheets и Google Calendar. Собственный сервер, отдельный OCR-сервис и ключ OpenAI API для этого пакета не требуются. Для работы нужен доступ к Codex и соответствующим Google-плагинам; лицензия пакета не включает сторонние подписки.

## Установка

Передайте Codex ссылку на этот репозиторий и попросите установить плагин Salon Assistant и подготовить отдельный рабочий проект. Репозиторий публичный: пароль GitHub не нужен. Агент читает [INSTALL.md](INSTALL.md), проверяет Python 3.10+ и Codex CLI, запускает `scripts/install_plugin.py --project <абсолютный-путь>`. Установщик регистрирует каталог, устанавливает плагин и проверяет его через Codex.

Затем откройте созданный рабочий проект в Codex, начните новую задачу и напишите «Привет». Мастер помогает подключить собственный Google-аккаунт, создать или привязать папки и таблицы, задаёт вопросы по одному и запрашивает образец клиентской базы файлом или скриншотом. Перед рабочими изменениями показывает конкретную сводку для подтверждения и проверяет сохранённый результат.

## Облачный запуск

Плагин можно использовать и в одном постоянном облачном проекте ChatGPT/Codex без локального `system/BOOTSTRAP.json`. При первом подтверждённом подключении мастер сохраняет в постоянных файлах этого проекта одну `system/CLOUD-PROJECT-CONTEXT.json`: стабильный ключ проекта, ID корня Google Drive и ID `system/КОНТЕКСТ-ПРОЕКТА.json`. Новая задача, Mac, телефон или браузер продолжают работу через эту же привязку. Если привязка отсутствует, конфликтует или аккаунт не подтверждён, рабочая запись останавливается до одного точного уточнения; плагин не ищет другие проекты и не создаёт замену базы.

## Что входит

| Навык | Назначение |
|---|---|
| `svetlana-assistant` | Начало сессии и выбор сценария |
| `svetlana-first-run` | Google-подключение, структура проекта и персонализация |
| `svetlana-client-photo` | Клиентская база и карточки по фото/скриншотам |
| `svetlana-calendar-booking` | Запись, перенос и отмена сеанса с проверкой базы и календаря |
| `svetlana-stock-photo` | Приход, расход и сверка остатков по фотографиям |
| `svetlana-update-base` | «Обнови базу»: клиентская база, карточки и итоги задач |

Идентификаторы `svetlana-*` сохранены от первого прототипа. Имя пользователя, обращение, услуги, график и материалы задаются в мастере. Значения по умолчанию — Санкт-Петербург и `Europe/Moscow`; их можно изменить явным запросом.

## Структура проекта

На Google Drive: `system`, `Клиенты`, `Склад` и таблица «Оперативная память». В «Клиенты» сразу создаётся нативная «Клиентская база»; предоставленные позже клиентские данные переносятся в тот же файл. В «Склад» находится «База данных склада». Настройки и журнал операций хранятся в `system`. Таблица лидов в объём Светланы не входит и не создаётся; оставшаяся от старой версии таблица сохраняется без изменений.

После настройки напишите **«Обнови базу»** в рабочем проекте. Подтверждённые клиентские сведения попадут в базу и карточку, результаты конкретной работы — в оперативку со ссылками. Уже подтверждённые факты сохраняются без повторного согласия. Неясные сведения уточняются; повторная команда без изменений не создаёт дублей. Сама команда не отправляет сообщения, не создаёт сеансы и не списывает материалы.

Плагин содержит шесть навыков и хранится отдельно от клиентского проекта. Локальная рабочая папка содержит инструкции и `system/BOOTSTRAP.json`; облачный проект — только постоянную облачную привязку. В обоих режимах профиль и рабочий контекст хранятся в Google Drive. Плагин появляется в Codex как Salon Assistant; установщик читает обратно версию, источник и включённое состояние. Google подключается отдельно. Прежний `install_project.py` сохранён для проектов со скиллами; их автоматическая миграция в плагин не выполняется.

## Готовность и ограничения

Для версии 0.8.2 прошли локальные тесты установщиков и сборка отдельного marketplace с шестью навыками; точные подтверждения приведены в [проверке версии 0.8.2](PLUGIN-VALIDATION.md). Облачная привязка проверена структурно, без реальных Google-записей. Сквозной сценарий на вымышленных Google-данных относится к предыдущему выпуску и описан в [архивном отчёте проверки](VALIDATION.md). Установка на устройстве пользователя, его Google-вход и качество чтения реальных фотографий проверяются отдельно при передаче.

Фото этикетки не доказывает фактический остаток. Нечитаемые данные не угадываются. Повторный скриншот или потерянный ответ не должны приводить к повторному списанию или второму сеансу. Проверка календаря не блокирует одновременные ручные изменения; при неоднозначном результате требуется сверка. Автосписание по услуге, рассылки клиентам и фоновая синхронизация не входят в эту версию.

В публичных исходниках нет рабочих таблиц, фотографий, заполненного профиля, OAuth-токенов или Google-ID разработчика. Рабочая папка пользователя хранится отдельно от репозитория. Для обновления legacy-проекта 0.6.2, 0.7.0, 0.8.0 или 0.8.1 до 0.8.2 агент использует `--upgrade` по [инструкции](INSTALL.md): установщик сохраняет Google-привязку и пользовательские файлы, останавливается при ручной правке исходников. Автоматическое обновление уже зарегистрированного plugin-mode пока не входит в пакет и не выполняется молча. Старые поля и таблица лидов сохраняются как совместимые данные, но больше не входят в настройку и не блокируют готовность.

Краткие правила эксплуатации и изменения рабочих правил находятся в [инструкции для Светланы](CLIENT-OPERATING-GUIDE.md).

## Разработка

Python 3.10+, стандартная библиотека:

```bash
python3 -B -m unittest discover -s tests -v
```

При изменении скиллов проверяйте реальные сценарии и ссылки. При отправке примеров и сообщений об ошибках используйте вымышленные данные. Пакет распространяется на условиях [MIT](LICENSE).
