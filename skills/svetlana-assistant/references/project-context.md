# Единый контекст проекта

Шесть навыков используют один и тот же resolver контекста. Он не ищет чужие проекты и не выбирает ресурс по одному имени.

## Режимы запуска

1. **Локальный проект.** Если в текущей рабочей папке есть `system/BOOTSTRAP.json`, прочитай его и по `context_file_id` открой связанный `system/КОНТЕКСТ-ПРОЕКТА.json` в Google Drive. Проверь `engine`, `deployment_id`, аккаунт и `resources.root_folder_id`.
2. **Облачный проект.** Отсутствие локального `BOOTSTRAP.json` не является ошибкой. Используй единственную явную облачную привязку текущего проекта: `system/CLOUD-PROJECT-CONTEXT.json` в постоянных файлах облачного проекта или точно указанный владельцем `context_file_id`/`root_folder_id`. После первого подтверждённого подключения сохрани эту привязку в облачном проекте; локальный указатель создавать не нужно.

Облачная привязка имеет вид:

```json
{
  "schema_version": 1,
  "binding_kind": "salon-assistant-cloud-project",
  "plugin_id": "svetlana-assistant@salon-assistant",
  "project_key": "stable-project-key",
  "account_email": "owner@example.com",
  "context_file_id": "drive-file-id",
  "root_folder_id": "drive-folder-id",
  "phase": "ready"
}
```

`project_key`, `context_file_id` и `root_folder_id` образуют одну привязку. Не создавай новую UUID или новый корень при новой задаче, новом устройстве, перезапуске или временной потере локальных файлов. Если облачная привязка отсутствует, повреждена, указывает на несколько кандидатов или аккаунт не подтверждён, останови зависимую запись и запроси один недостающий вход. Не ищи корень глобальным поиском и не создавай дубликат.

После разрешения привязки прочитай облачный `system/КОНТЕКСТ-ПРОЕКТА.json`. Все шесть навыков используют только его `resources`, `profile`, схемы и `setup`; различия между задачами не создают новый контекст. Для записи применяй [политику операций](operations.md), сохраняя `operation_id` в том же облачном `system/operations`.

Облачный режим не обещает наличие Google-инструмента или доступ к данным. Сначала проверь реальный метод, аккаунт, MIME, родителей, схему и права. Подготовленный локальный файл, ссылка из переписки или открытая вкладка не являются подтверждением облачной привязки.
